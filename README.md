## Hello — I'm Patricio 👋

I'm a **Software Engineer at Howdy** focused on full-stack product engineering and applied AI. I build production web applications, internal platforms, developer tools, browser extensions, and LLM-enabled workflows with **TypeScript, React, Next.js, Node.js, PostgreSQL, and modern AI tooling**.

My sweet spot is translating a real operational problem into a clean product: shaping the UX, designing the data model and APIs, integrating external services, adding tests and observability, and shipping an experience people can rely on.

FRONTEND SYSTEMS        React, Next.js, Vue, TypeScript, accessible responsive interfaces

## How I work

- **Outcome-first:** understand the user and business constraint before choosing the architecture.
- **End-to-end ownership:** move comfortably from UX and frontend systems through APIs, data, deployment, and production support.
- **Practical AI:** use models where they create measurable leverage, with validation, failure handling, and human control.
- **Clear collaboration:** document decisions, keep feedback loops short, and leave systems easier to maintain than I found them.
